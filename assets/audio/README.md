# 音訊資料夾（目前沒有音檔）

| 資料夾 | 用途 | 在 story-data.js 填寫的位置 |
| --- | --- | --- |
| `narration/` | 旁白 | 每一幕的 `audio.narration` |
| `voice/` | 兔兔、熊大角色配音 | 每一幕的 `audio.voice` |
| `bgm/` | 背景音樂 | episode 的 `bgm` |
| `sfx/` | 音效 | 每一幕的 `audio.sfx` |

建議使用 `.mp3`（iPhone、Android、電腦都支援）。檔名建議用章節與幕號，例如 `voice/ch1-02.mp3`。

沒有填路徑的欄位，網站會顯示「尚無音檔」，不會假裝已有配音。
